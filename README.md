# YouTube Ultimate Downloader - Full Resolution (8K / 4K / 2K / 1080p / MP3)

Công cụ tải video YouTube đầy đủ mọi độ phân giải với giao diện Web hiện đại, tích hợp tự động **FFmpeg** để ghép nối hình ảnh và âm thanh chất lượng cao nhất không bị mất tiếng (lossless).

---

## 🚀 Cách Chạy Nhanh Nhất (1-Click)

### Cách 1: Chạy bằng file `run.bat` (Khuyên dùng)
- Vào thư mục `c:\Code\downloadclipyt`
- **Nháy đúp (Double-click) vào file `run.bat`**
- Trình duyệt web sẽ tự động mở lên giao diện tải video tại: **`http://127.0.0.1:8000`**

### Cách 2: Chạy bằng dòng lệnh (Terminal / PowerShell)
Mở PowerShell tại thư mục dự án và gõ:
```bash
python app.py
```
Sau đó truy cập: [http://127.0.0.1:8000](http://127.0.0.1:8000)

## ✨ Các Tính Năng Nổi Bật

1. **Đầy đủ mọi độ phân giải**:
   - 8K (4320p 60fps)
   - 4K Ultra HD (2160p 60fps)
   - 2K Quad HD (1440p 60fps)
   - Full HD 1080p (60fps / HDR)
   - 720p HD, 480p, 360p
2. **Tách nhạc âm thanh chất lượng cao**:
   - MP3 320kbps (Cao nhất)
   - MP3 256kbps
   - M4A (AAC gốc không nén lại)
   - WAV (Lossless)
3. **Tự động ghép nối FFmpeg**:
   - Video YouTube chất lượng cao (1080p trở lên) luôn tách riêng hình ảnh và âm thanh. Tool tự động kích hoạt FFmpeg ngầm để ghép thành file MP4/MKV hoàn chỉnh có âm thanh rõ nét.
4. **Theo dõi tiến trình thời gian thực**:
   - Thanh tiến trình phần trăm (%), tốc độ tải (MB/s), thời gian còn lại (ETA).
5. **Quản lý thư viện video**:
   - Nút **"Mở file ngay"** và **"Thư mục tải về"** mở trực tiếp trong Windows Explorer chỉ với 1 click.
   - Thư mục lưu mặc định: `c:\Code\downloadclipyt\downloads\`
